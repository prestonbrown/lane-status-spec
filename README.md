# Lane Status Surface

An open RFC for publishing multi-material filament lane state from Klipper printers, so that
web UIs, touchscreens and slicers can all see what is loaded in each lane.

The first draft, RFC 0001, is open for review as a pull request in this repository. Comment on
any line there, and use Discussions for the open questions it lists.
